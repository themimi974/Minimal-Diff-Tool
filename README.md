# Minimal Diff Tool

A single-page, dependency-free side-by-side code diff tool. Paste the original and modified code, and it shows line- and word-level changes.

Live: https://themimi974.github.io/minimal-diff-tool/

## Hosting

The site is the static `index.html` at the repo root, deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.

One-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
